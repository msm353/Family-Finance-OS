# FFOS 0.1.2-beta

این نسخهٔ آزمایشی اندروید، رابط جدید FFOS را به همان برنامهٔ آفلاین ثبت هزینه اضافه می‌کند. فایل `FFOS-v0.1.2-beta.apk` را از بخش **Assets** دانلود و روی گوشی نصب کنید.

## تغییرات

- صفحهٔ اصلی روشن با فهرست هزینه‌های اخیر و مقایسهٔ هزینهٔ ماه جاری با بازهٔ مشابه از ماه شمسی قبل
- صفحهٔ مستقل برای ثبت و ویرایش هزینه
- فهرست، جستجو و فیلتر هزینه‌ها در چیدمان تازه
- گزارش شش ماه اخیر، تفکیک هزینه‌ها بر اساس دسته‌بندی و روش پرداخت
- صفحهٔ جداگانه برای پشتیبان‌گیری، بازیابی و پاک‌کردن داده‌ها

داده‌ها همچنان فقط روی همان دستگاه ذخیره می‌شوند و همگام‌سازی خودکار ندارند. ساختار داده نسبت به نسخهٔ قبل تغییر نکرده است.

**پیش از نصب:** این APK با امضای آزمایشی ساخته شده است. ممکن است به‌دلیل تفاوت امضا، روی APK آزمایشی قبلی نصب نشود. پیش از حذف نسخهٔ قبلی، از داخل آن فایل پشتیبان JSON بگیرید، ذخیره‌شدن فایل را در گوشی بررسی کنید و پس از نصب نسخهٔ تازه آن را بازیابی کنید. حذف برنامه داده‌های محلی آن را نیز پاک می‌کند.

برای راهنمای کامل، [مدیریت داده‌ها](https://github.com/msm353/Family-Finance-OS/blob/develop/docs/DATA.md) را ببینید.

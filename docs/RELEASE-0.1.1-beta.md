# FFOS 0.1.1-beta

نخستین فایل نصبی اندروید FFOS. فایل `FFOS-v0.1.1-beta.apk` را از بخش **Assets** همین صفحه دانلود کنید و در گوشی باز کنید تا نصب شود. همهٔ فایل‌های لازم در APK قرار دارند و برنامه پس از نصب آفلاین اجرا می‌شود.

در این نسخه، گزینهٔ «پاک‌کردن همهٔ هزینه‌ها» با تأیید پیش از حذف اضافه شده است. راهنمای کامل در [مدیریت داده‌ها](https://github.com/msm353/Family-Finance-OS/blob/develop/docs/DATA.md) آمده است.

**انتقال داده از نسخهٔ وب:** داده‌های مرورگر خودکار به برنامهٔ اندروید منتقل نمی‌شوند. در نسخهٔ وب فایل پشتیبان JSON بگیرید، سپس آن را در برنامهٔ اندروید بازیابی کنید. برای ذخیرهٔ پشتیبان در اندروید، از پنجرهٔ اشتراک‌گذاری یک مقصد انتخاب و وجود فایل را بررسی کنید.

این APK یک نسخهٔ آزمایشی با امضای اشکال‌زدایی است. ممکن است نصب نسخه‌های بعدی روی آن نیاز به حذف برنامهٔ قبلی داشته باشد؛ پیش از حذف یا تعویض نسخه، حتماً فایل پشتیبان JSON بگیرید.

# Family Finance OS (FFOS)

FFOS یک برنامهٔ آزمایشی برای ثبت و بررسی هزینه‌های خانوادگی است. داده‌ها در مرورگر همان دستگاه ذخیره می‌شوند و پس از بارگذاری اولیه، برنامه بدون اینترنت هم کار می‌کند.

**نسخهٔ در حال آزمون:** `0.2.0-beta`؛ نسخهٔ منتشرشدهٔ قبلی `0.1.2-beta`. [وضعیت آماده‌سازی و آزمون گوشی](docs/BETA-0.2.0.md)

[نقشهٔ راه محصول](ROADMAP.md) · [طرح اولیهٔ هستهٔ مالی](docs/FINANCIAL-CORE.md) · [قرارداد داده و مهاجرت نسخهٔ ۲](docs/DATA-CONTRACT-V2.md)

## امکانات فعلی

- حساب بانکی، نقدی و کیف پول با ماندهٔ آغازین، درآمد و انتقال هم‌ارز به تومان
- موجودی تا امروز، حذف قابل بازگردانی، بایگانی حساب و تاریخچهٔ تغییرات
- پشتیبان کامل نسخهٔ ۲ و مهاجرت هزینه‌های قبلی با حفظ منبع اصلی

- ثبت، ویرایش و حذف هزینه با تاریخ شمسی، دسته‌بندی و روش پرداخت
- جستجو، فیلتر بازهٔ تاریخ و مرتب‌سازی هزینه‌ها
- خلاصهٔ هزینه‌ها و گزارش ماهانه و روش‌های پرداخت
- خروجی CSV از هزینه‌های فیلترشده
- پشتیبان‌گیری کامل JSON و بازیابی آن با تأیید پیش از جایگزینی داده‌ها
- نصب به‌صورت برنامهٔ وب و استفادهٔ آفلاین پس از اولین بازدید آنلاین

## استفاده روی گوشی

نسخهٔ میزبانی‌شده در [نشانی FFOS](https://ffos-msm353.new-parandcity.chatgpt.site) فعلاً دسترسی خصوصی دارد. آن را با حساب مجاز باز کنید. در مرورگر، گزینهٔ «نصب برنامه» یا «افزودن به صفحهٔ اصلی» را انتخاب کنید. برای کار آفلاین، برنامه باید یک‌بار هنگام اتصال به اینترنت کامل بارگذاری شده باشد.

هزینه‌ها در پایگاه دادهٔ مرورگر هر دستگاه نگه‌داری می‌شوند. بین گوشی و رایانه همگام‌سازی خودکار وجود ندارد. پیش از پاک‌کردن داده‌های مرورگر یا تعویض دستگاه، از بخش «پشتیبان‌گیری و بازیابی» فایل JSON بگیرید. خروجی CSV برای گزارش‌گیری است و جایگزین فایل پشتیبان JSON نیست.

برای پاک‌کردن همهٔ هزینه‌ها از داخل برنامه و شروع دوباره، [راهنمای مدیریت داده‌ها](docs/DATA.md) را ببینید.

## نصب روی اندروید از فایل APK

از بخش [انتشارهای گیت‌هاب](https://github.com/msm353/Family-Finance-OS/releases) فایل APK نسخهٔ جدید را دانلود کنید. پس از پایان دانلود، فایل را در گوشی باز کنید و نصب را انجام دهید. برنامه پس از نصب، بدون نیاز به اینترنت اجرا می‌شود و داده‌ها را در فضای محلی خود نگه می‌دارد.

نامزد `0.2.0-beta` با کلید ثابت و شمارهٔ ساخت ۵ ساخته می‌شود و روی APK قبلیِ دارای همین کلید نصب می‌شود. APK منتشرشدهٔ قدیمی `0.1.2-beta` امضای آزمایشی داشت. اگر نسخهٔ بعدی روی آن نصب نشد، پیش از حذف نسخهٔ فعلی حتماً پشتیبان JSON بگیرید؛ حذف برنامه، داده‌های محلی آن را هم پاک می‌کند.

برای انتشار نسخه‌های بعدی با امضای پایدار، [راهنمای امضای APK](docs/ANDROID-SIGNING.md) را ببینید.

نسخهٔ APK فضای ذخیره‌سازی جداگانه‌ای از نسخهٔ وب دارد. برای انتقال هزینه‌های قبلی، در نسخهٔ وب فایل پشتیبان JSON بگیرید و در برنامهٔ اندروید بازیابی کنید. در برنامهٔ اندروید، دکمهٔ «دریافت فایل پشتیبان» پنجرهٔ ذخیره یا اشتراک فایل را باز می‌کند؛ ذخیره‌شدن فایل را پیش از حذف داده‌ها بررسی کنید.

## اجرای محلی

به Node.js و npm نیاز دارید:

```bash
npm ci
npm run dev
```

برای بررسی نسخهٔ تولیدی:

```bash
npm test
npm run lint
npm run build
npm run preview
```

آدرس توسعه معمولاً `http://localhost:5173` و پیش‌نمایش تولیدی معمولاً `http://localhost:4173` است. سرویس آفلاین فقط در نسخهٔ تولیدی ثبت می‌شود. نصب برنامه به HTTPS یا محیط محلی مرورگر نیاز دارد.

## وضعیت پروژه
